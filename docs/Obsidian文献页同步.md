# Obsidian 文献页同步

更新：2026-10-30。批注采用 Lumen → Obsidian 单向同步；属性及阅读笔记支持 Lumen ↔ Obsidian 双向编辑。

## 启用

1. 在 Zotero One 设置的「笔记」中关闭「自动模式」。当前安装版对应 `extensions.zotero.zoteroif.obsidianautoupdatenotes`；Lumen 检查该目录的设置，不能确认已关闭时拒绝接管。Zotero 正在运行时，刚修改的设置可能尚未落入 prefs.js，应先正常退出 Zotero、再重新打开确认。
2. Lumen 设置 → 文献笔记 → 选择 `PKM/1-Reference/文献/notes`，开启全局同步功能。首次选目录不批量改写旧页；随后用文献笔记侧栏顶部的开关，逐篇选择是否同步。
3. 打开一篇文献，在文献笔记侧栏开启「同步」。无需运行或先关联 Zotero：已有题录会自动填写；在线优先使用本地 API，关闭时只读查询本地文献库。首次建页只短暂等待题录，耗时查找继续在后台进行，应用约每5秒对账，未关联文献约每10秒重试。首次已有唯一 Zotero 文献页时原位接管；后续找到唯一附件后为本页补链接和空字段，保留自填内容。歧义附件、同身份多页不猜测合并，也不阻断当前阅读笔记。
4. 已开启当前文献同步后，后续批注成功保存会自动更新该页。关闭当前文献同步会取消尚未执行的防抖任务，保留已生成页面；未关联或已暂停的文献不会因保存批注被自动接管。已关联文件在应用运行期间后台对账，重启后重新核对；不同附件共用父条目文献页。

## 页面与编辑

既有页面按 YAML `itemLink` 的 Zotero 库与父条目 key 匹配，保留原路径、YAML 和原正文。新页模板为题录属性、文献标题、阅读笔记、按附件分节的高亮与批注。阅读笔记位于全部高亮之前；不再生成「文献信息」与「我的整理」重复小节。批注区用二级标题「批注」，每条采用 Obsidian 原生引用块，页码前显示对应高亮色圆点；显示摘录、评论正文和原文链接，不再为每条增加同步标记。每附件仅保留一对 %% 隐藏注释，阅读笔记也保留一对；阅读视图不显示，编辑/源码模式可能显示。个人总结、双链、标签和待办可写在 Lumen 隐藏标记之外，原有自由内容会保留。不要手工复制受管标记到第二份页面。

本版不回写 PDF/EPUB：原文批注区始终以 Lumen 为准。Obsidian 中改写批注文字、摘录或删除单条后，后续对账先保存修改页副本，再恢复源批注；不因此暂停整篇。需要长期保留的个人文字请写入阅读笔记或生成区之外。属性和阅读笔记仍可在两端编辑，各字段版本冲突独立处理。只有身份重复、文件不可写、无法辨认的外围边界损坏等无法安全处理的情况保留错误保护。文献页在所选目录内改名可重新识别，重复身份拒绝猜测；源文件移动和关联切换仍需人工处理。


## 接管与恢复

首次接管既有页前保存可恢复副本，路径显示于同步记录。同步状态与共同版本位于 `~/Library/Application Support/com.jn.lumen/literature-sync.json`；备份位于同目录的 `literature-sync-backups/`。恢复前先停用自动同步，将当前页面另存，再复制所选备份；同步记录也需与页面版本一致，不能只删除状态文件后强行接管已有 Lumen 标记。停用后 Markdown 和原文批注仍可独立使用。Zotero One 自动模式只应在明确交还目录写入权后重新开启。

## 已验证与限制

合成 PDF/EPUB 验证多行正文、多附件、原页面保护、外部批注改写后单向恢复并备份、阅读笔记与属性保留、备份、改名与重复身份。真实 Zotero API 完成只读附件匹配。隔离 GUI 已确认保存批注自动生成页面及 Obsidian 修改后保护原 PDF。

PDF/EPUB 在副本上完成单文档正文往返试验，但尚未证明后台写入与已打开阅读器的统一保存协调可靠，因此按方案回退为单向；不提供双向开关或冲突合并界面。文件协调和写前逐字复核保护已观测修改，无法承诺对不遵守文件协调的其他进程实现跨应用原子事务。

用户在同一份 1058 页、357 MiB 扫描书副本上分别进行了真实触控板操作，确认基线操作正常、同步候选版体验相当。最终构建已补同书触控板对照、内存取样、真实Obsidian双向笔记与属性、批注跳转和缩略图选中核验，结果见VERIFY；不推断任意文档或长期压力均通过。原件未改。


## 属性和阅读笔记侧栏（2026-10-28）

开启同步后，侧栏增加笔记图标，提供同步、在 Obsidian 打开、属性编辑和阅读笔记。新建页面使用附件文件名（去扩展名），碰撞时追加条目标识；已有路径保留。标题属性取 Zotero 文献题名，与页面文件名独立；没有题录的本地文献留空，可手工填写；多附件共用先接管的页面。此前误设为附件文件名的标题会在备份后修正，用户自行修改的其他题名保留。

首次增加期刊、评价、总结，期刊取 Zotero publicationTitle。评价显示五颗空心星，可点击或拖动选择零到五星，再点行内勾号保存；Markdown 保存为「★★★☆☆」这类文本，Obsidian 修改星星或 0–5 数字后也能被 Lumen 读取。旧文字评价不会自动丢弃，选择星级后保存才替换。星形与属性正文同字号，浅色和深色主题分别使用可辨识的金黄色。日期使用 Zotero 题录的发表日期（来源只有年份时显示年份）；侧栏的修改时间是 Markdown 文件的实际修改时间，约两秒刷新一次，为只读显示，不写入 YAML。旧版本生成的时间属性保留，用户可自行删除。删除的属性不会在每次同步时重新补回。自定义文本属性可添加、编辑及删除；列表、对象等复杂 YAML 和 itemLink 身份属性只读。属性修改只作用于 Markdown，不回写 Zotero 数据库。

打开侧栏时每两秒读取外部修改。保存按字段核对原值，只修改相应字段；同字段外部已改时保留文件和草稿，提示冲突，可点击「载入外部版本」。阅读笔记在同页独立区域，支持 Markdown、多行、双链，采用相同冲突保护。清空仅清草稿，保存后才落盘；退出前请保存。旧「我的整理」标题删除，其中已有的自由正文原样保留。跨应用文件协调不构成分布式原子事务，避免其他插件同时导出整页。

## 高亮、批注与便签（2026-10-29）

PDF 右键菜单分别提供「高亮」「新建批注」「评论／便签」。高亮要求主动选中文字，仅标记原文；新建批注要求选区或命中已有高亮，已有高亮直接载入并修改原正文；评论／便签始终创建独立页面便签，即使当前有文字选区也不会变成高亮。无选区且未命中高亮时，前两个入口禁用。点击高亮的浮动菜单使用「新建批注」，打开对应正文的编辑状态；侧栏的独立创建入口改名「新建便签」。

新布局首次更新前保留旧页备份。设置中的 Zotero One 提示小字已按要求移除，目录写入归属检查继续生效。当前批注同步仍单向，属性和阅读笔记双向编辑不变。当前验证见 [验证手册](VERIFY.md)。

## 笔记面板操作（2026-10-29 更新）

顶部开关控制当前文献的同步，不改变其他文献。属性可折叠，直接点击文本修改，有更改时显示勾号；每行省略号菜单提供删除、载入外部版本，评价菜单也可清除星级。加号用于添加属性。阅读笔记使用透明的原生文本编辑器，保留多行、中文输入法、emoji和普通Markdown；修改后在小节标题处保存。底部说明小字已移除。同步关闭时可保留草稿，保存到文献页的入口禁用；恢复开关后可以保存。

颜色信息保留在原文和内部映射中，文献页不再输出十六进制颜色标签。已有页面升级到 pageStyleVersion=4 时先备份并更新生成区，个人正文与原有属性保留；旧版本增加的时间字段不会自动删除。最新批注单向刷新及紧凑布局验证见 verification/literature-sync-20261029/export/README.md。
