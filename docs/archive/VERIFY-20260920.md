# 2026-09-20 PDF 滚动与项目维护验证

基于用户再次修改后的 `496f464`，启动时工作树干净。保留原图标、多标签、EPUB 排版面板、逐段翻译及最新底部工具条。对话范围见 [决策记录](DECISIONS-20260920.md)。

## 修复与清理

- 最终改为 PDFKit `PDFPage.draw(with:to:)` 分块着色，原生 tile 缓存结果；移除 Core Image contentFilters、整屏 SwiftUI 混合与 compositingGroup。黑映射为正文色、白映射为纸色。缩略图在后台一次着色后缓存，不再滚动时合成。
- `PDFOriginalRendering` 在保存线程禁用显示色调；OCR 使用原始绘制。主题切换保留精确滚动位置、倍率与选区。关闭 PDF 时卸载文档、停止视口任务并解除第一响应者关系。
- 缩略图面板隐藏时关闭每帧视口几何调度；面板重新打开时恢复。保留独立文档、串行渲染、有界缓存与版本失效逻辑。
- 关闭标签、其他标签、窗口统一取消全文任务、AI 流、智能目录/摘要、EPUB 翻译，释放桥接回调并保存阅读位置；迁移到独立窗口不当作关闭。
- 移除阅读视图挂载时重复的 AI bind，避免重复磁盘读取、清空草稿和停止现有回答。
- EPUB 章节通知由强捕获 View 的闭包改成发布计数，关闭后解析结果通过取消检查丢弃。PDF/EPUB 的反向状态回调使用弱引用。
- 删除无调用的 `AIKeychain.swift`（247 行）、`KeychainAudit.swift`（112 行）、失效命令行入口与无引用的动态插值说明常量。用户已有钥匙串条目不动。仍用于复现的渲染对照通道保留。
- README 与架构文档中“API Key 只进 Keychain”的过时说明已更新为实际的本地凭据文件实现。

没有新增第三方依赖，没有降低滚动中的清晰度，没有修改 PDFKit 私有属性，也没有加入自制平滑滚轮算法。

## 定位依据与边界

Apple 明确说明 [contentFilters](https://developer.apple.com/documentation/appkit/nsview/contentfilters) 作用于视图及子层；[layerUsesCoreImageFilters](https://developer.apple.com/documentation/appkit/nsview/layerusescoreimagefilters) 说明附加 Core Image 会使图层层级回到应用进程内合成。最终使用公开 [PDFPage 自定义绘制](https://developer.apple.com/documentation/pdfkit/custom-graphics) 与 Core Graphics 混合。

进程采样同时出现 PDFTilePool、PDFPageLayerTile、Core Graphics 与 JPEG 解码；主线程在热身后的大部分采样里空闲。因此不能把问题全部归因于 SwiftUI body，也不能把首轮高峰全部归因于滤镜。

用户实机确认原色流畅、主题卡顿，是最终调整渲染路径的直接依据。注意：`cacheDisplay` 离屏截图可能绕过 PDFKit tile，不能据其白纸推断主题失效；最终使用 CUA 真实屏幕检查暖纸和暮蓝着色。
